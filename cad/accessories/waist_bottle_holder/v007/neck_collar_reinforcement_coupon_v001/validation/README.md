# Validation scope

`validation_report.json` distinguishes CAD hard checks from physical evidence. CAD PASS does not promote any coupon to production authority.

The report covers finished B-rep opening measurements, phi26.2 ID gauge clearance, ring dimensions, exact V007 tab reuse, root/gusset dimensions, transverse throat sections, material volumes, theoretical opening deflection, eight-station receiver slide collision, STEP reload, binary-STL topology/volume, protected V007 hashes, and start/end Git state.

Expected non-PASS states are one known physical FAIL for the broken original V007 collar root and six PENDING candidate fit/durability states.
