# PHYSICAL TEST PROTOCOL — v003 SIDE-LOAD LABYRINTH

Print only the lower/upper `split_labyrinth_side_load_coupon_v003` pair first. Do not thread either cable end through a hole, disconnect a molded connector, or cut a cable.

## V003 SIDE-LOAD TEST

| Record | Result |
|---|---|
| cable end threaded through hole | NO / YES |
| camera cable Ø3.8 placed from side/top | YES / NO |
| extension cable Ø4.0 placed from side/top | YES / NO |
| upper shell closes | YES / NO |
| cable pinched | NONE / YES |
| cable can slide slightly longitudinally | YES / NO |
| connector disconnection required | NO / YES |
| cable cutting required | NO / YES |
| RESULT | PASS / FAIL |

PASS requires `NO END THREADING`, `NO CUTTING`, and `NO PINCHING`. Repeat remove/reinstall five times with each real cable. Record any jacket marking, shaving, cap displacement, seam lift, or progressive tightness. Any connector disconnection or cable cutting requirement is immediate FAIL.

## COLORED-WATER TEST

Run only after side-load assembly PASS. Place fresh dry tissue in the chamber-side `WITNESS_BAY`.

| Record | Level | +5° | -5° |
|---|---|---|---|
| water introduced | ___ mL | ___ mL | ___ mL |
| target volume range | 1–3 mL | 1–3 mL | 1–3 mL |
| drain exits | YES / NO | YES / NO | YES / NO |
| witness | DRY / TRACE / WET | DRY / TRACE / WET | DRY / TRACE / WET |
| pooling after 5 min | NONE / YES | NONE / YES | NONE / YES |
| result | PASS / HOLD / FAIL | PASS / HOLD / FAIL | PASS / HOLD / FAIL |

`DRY` is PASS target, `TRACE` is HOLD, and `WET` is FAIL. Confirm the 2.5 mm drain is visibly open before each run and inspect it afterward for debris.

## AFTER_PRINT order

1. side-load Ø3.8 cable
2. side-load Ø4.0 cable
3. close upper
4. check cable pinch and slight longitudinal slide
5. remove/reinstall ×5
6. introduce colored water
7. inspect witness bay
8. repeat drain test at ±5°
9. print/assemble full shell only after all gates PASS

## Full-shell gate

Do not promote the full shell until side-load assembly PASS, no cable pinching, no end threading, drain PASS, and witness DRY are all recorded. Full-shell dry assembly, unpowered spray, powered USB, outdoor rain, heavy rain, and long-duration exposure remain separate later gates.
