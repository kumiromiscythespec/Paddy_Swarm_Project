# Phase 3I-G Design Authority

Phase 3I-G is a hydraulic prototype, not a production release. The authoritative
path is lowest-stage drops → terminal tray → top-vented downcomer → removable
bottom diffuser → upward displacement → opposite 112 mm wide weir → open gutter
air break → one independent 25 mm return per tower → central trough.

The 30° stage sequence and the dry Ø100 core from Phase 3I-F remain unchanged.
The measured mast reference is SUS SF-20・20 SF9-202, 19.9 × 19.9 mm, with no
observed twist and acceptable straightness. The mast does not carry the wet
stack vertically. Primary tank and stack loads terminate in the metal shelf/base.

No final hose or cleanout diameter is inferred. Both pads are blank with pilot
marks; fitting selection remains `DIMENSION_PENDING`.
