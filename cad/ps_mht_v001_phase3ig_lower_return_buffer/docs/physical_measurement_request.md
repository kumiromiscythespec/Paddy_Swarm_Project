# Physical Measurement Request

Before fitting CAD is released, measure with calipers and record manufacturer/part:

- Normal-return bulkhead thread major/minor diameter, shoulder diameter, seal seat,
  usable clamping length, nut envelope, hose barb OD/ID, and required tool clearance.
- Cleanout plug/valve thread, gasket seat, minimum clear bore (12 mm minimum; 15 mm
  preferred), external envelope, and center-height requirement.
- Central trough inner top and floor length/width, wall slope, corner radii, usable
  water-depth datum, overflow rim, and return inlet Z.
- Final metal shelf clear opening, crossbar section, level tolerance, tank restraint,
  and removal clearance.
- Any transparent D08 container's wall thickness, rim geometry, clear internal
  envelope, clamp-safe zones, and chemical compatibility.

Keep each value `PHYSICAL_MEASUREMENT_PENDING` until measured. Do not transpose
catalog nominal dimensions into the CAD authority without identifying the part.
