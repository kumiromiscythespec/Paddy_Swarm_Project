# Failure Modes

| Failure | Detection | Current control |
|---|---|---|
| PETG layer/corner leak | D01 and 24 h hold | 3 mm walls, 4 mm floor, R18 corners |
| Point jet / sediment lift | Dye Test 1 | horizontal outlet and 100 × 9 mm diffuser slot |
| Short circuit to weir | Dye Tests 1–2 | opposite-end inlet/weir; baffle interface reserved |
| Dead zone | color replacement time | add baffle only after evidence |
| Normal outlet obstruction | Test 3 | open gutter and independent emergency path |
| Tank overfill | Test 4 | Z94 visible overflow below Z105 rim |
| Siphon/backpressure | Tests 2–3 | top vent and atmospheric gutter air break |
| Drain-pad crack | D05 drilling coupon | blank reinforced full-tank pad |
| Floor leak from pipe | visual audit | zero tank-floor penetrations |
| Printed support overload | assembly inspection | metal shelf/base is primary load path |
| Return cross-flow | hose trace | four independent hoses to trough |
| Maintenance blockage | cleaning trial | removable open plenum, no fine holes/filter |
