# 印刷前・印刷後チェックリスト

## 校正前

- [ ] 購入するG1/2バルクヘッド継手の実測外径を測った
- [ ] 市販逆止弁の外径とホース径を測った
- [ ] 使用するシリコン平パッキンまたはOリングを決めた
- [ ] TPU 95Aを乾燥した

## CAD生成後

- [ ] `python -m compileall .` が成功した
- [ ] `python build_all.py` が成功した
- [ ] 本体と蓋の8穴が一致する
- [ ] 蛇腹、板、リングの8穴が一致する
- [ ] すべてA1の造形範囲内である

## 印刷後

- [ ] 積層割れがない
- [ ] シール面に大きな段差がない
- [ ] ボルト穴周囲が白化していない
- [ ] TPU谷部にピンホールがない
- [ ] タンクを-5/-10/-15/-20kPaで段階試験した
- [ ] 蛇腹を100回、500回作動させた
- [ ] 水250mL捕集時に蛇腹側へ水が抜けない
