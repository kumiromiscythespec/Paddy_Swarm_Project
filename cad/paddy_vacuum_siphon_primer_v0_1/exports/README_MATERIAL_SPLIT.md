# Paddy Vacuum Siphon Primer v0.1
## PETG / TPU 材質別エクスポート

フォルダ構成：

- PETG/STL
- PETG/STEP
- TPU/STL
- TPU/STEP
- MATERIAL_MANIFEST.csv

### TPU分類
- PVSP-BL-001：交換式蛇腹
- PVSP-BL-009：足踏み面滑り止め
- PVSP-CAL-003：TPU蛇腹壁厚校正片

### PETG分類上の注意
PVSP-BL-006 guide_bushing は設計仕様上「PETGまたはTPU」ですが、
今回のZIPでは標準案としてPETGフォルダへ分類しています。
TPUで試す場合は同ファイルをTPUフォルダへコピーして印刷してください。
