# Phase 3I-D Bambu Studio review checklist

Use Bambu Lab A1, 0.4 mm nozzle, PETG Basic, 0.20 mm layer height, support OFF, brim OFF, registered vertical orientation and exactly one object per new project.

Review in this order: frozen Phase 3I-C D01, D02, D03; Phase 3I-D D04D; Phase 3I-D D05D; upper coupon; lower coupon. Do not use old Phase 3I-C D04 or D05 in this progression.

For every object record:

```text
floating_region_warning:
detached_islands:
unanchored_bridge_lines:
wall_interruption:
thin_independent_towers:
automatic_support_generated_location:
first_warning_layer:
first_warning_z_mm:
suspect_feature:
```

CAD validation is not a slicer pass. Do not print either coupon until both coupon slicer reviews pass. The full stage remains prohibited.
