# Phase 3I-F Bambu Studio checklist

Review one object per project on Bambu Lab A1, 0.4 mm nozzle, PETG Basic and 0.20 mm layers. Keep the registered orientation and supports off.

For the fit-coupon plate, confirm all three bodies start on layer one, holes remain open and no thin detached rings appear. For the held puck and cap, inspect the square mast opening, both M5 holes and every perimeter layer. For the full module, inspect the Phase 3I-E D01–D05 progression, standpipe crowns, landing ramps, clocking datums and stacking guides.

Record floating-region warnings, detached islands, unanchored bridges, wall interruption, first warning layer/Z, estimated time and material. CAD completion does not constitute a Bambu Studio pass.
