# BBOX wiring chimney v003 local gland recess

Test C2.4 first, then B2.2 if C fails, then A2.0 only if required. For each: (1) insert PG9 gland; (2) verify Ø15.2 fit; (3) install locknut; (4) finger-thread; (5) tighten with actual tool; (6) verify flat seating; (7) inspect visible engagement; (8) check hand-load rotation; (9) remove; (10) repeat; (11) inspect whitening, cracking, floor deformation and recess-edge cracking; (12) verify OD9.6 cable routing. Maximum fully passing wall thickness becomes authority.
