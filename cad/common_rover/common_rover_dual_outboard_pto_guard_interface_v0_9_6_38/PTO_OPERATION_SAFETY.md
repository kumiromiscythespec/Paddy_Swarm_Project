# Common Rover dual outboard PTO guard interface v0.9.6.38

## Required sequence

`DRIVE -> STOP -> DISENGAGE -> LOCK/BRAKE -> PTO ENGAGE -> WORK -> PTO DISENGAGE -> DRIVE RESTORE`

DRIVE/PTO simultaneous engagement is prohibited. Zero speed and positive mechanical lock/brake are required before PTO handling. Powered test and field use are NOT_APPROVED.
