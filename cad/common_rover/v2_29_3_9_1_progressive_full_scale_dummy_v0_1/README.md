# Progressive Full-Scale Assembly Dummy v0.1

This source-only lane turns the preserved Common Rover v2.29.3.9.1
authority and Assembly Interface v0.1 concepts into a staged, full-scale
placement and fit dummy kit.

The generated parts are not a rover, not load-rated, not waterproof, and not
approved for electrical or field use.  Successful first-side prints remain
usable in the final visual assembly dummy; the workflow does not require a
standalone coupon campaign.

## Authority reuse

`authority_adapter.py` imports the existing corrected Assembly Interface v0.1
authority adapter and reads all controlled dimensions from it.  This lane does
not restate controlled dimensions as independent constants.

The selected architecture is:

- PROFILE-3: printed 20 x 20 envelope-only dummy rails because no supplier
  profile section, T-nut, tolerance, or slot geometry is selected.
- Independent FRONT and REAR BBOX support representations, both marked
  `DUMMY ONLY`, `NO LOAD`, and `NOT STRUCTURAL`.
- Legacy Grade 0 float compatible interface kit with FLOAT-2 visual overlap.
  The audited nominal width is below the registered target, but the
  tolerance/inclination case exceeds it, so operational float-width validation
  remains HOLD.
- Integral positive stops, asymmetric keys, seated indicators, pin windows,
  and a secondary-only retainer cover.

## Physical-connectivity correction

`generate_connectivity_correction.py` preserves the original 19 STL files
byte-for-byte and adds 14 removable, support-free, dummy-only connection
parts.  The resulting 33-part kit has an explicit physical connection graph,
a corrected acyclic print dependency graph, and no loose positioning part.

The correction does not infer PROFILE-3 slots, add direct rail holes, approve
T-nuts, or generate an unknown float body.  Central and float-interface dry
dummy completeness are PASS; float-body and float-equipped completeness
remain HOLD.  AI-10 is reservation-only and remains
`NOT_YET_AUDITED`.

## Printed numbers

The repository precedent `PS-<machine>-<stage>-<category>-<serial>-R00` is
used with machine `PR`, stage `A1`, existing category codes, and a lane-local
300-series allocation.  Since the repository has no global serial allocator,
`GLOBAL_PART_NUMBER_RATIFICATION = HOLD`.

Every exported part is physically engraved with its complete part number and
required orientation/interface/classification markings on a non-functional
identification panel.  Filename-only or metadata-only identification is
rejected.

## Final-gate fixture separation

The base tests accept only manifest schema
`PS_PROGRESSIVE_FULL_SCALE_DUMMY_KIT_V0_1` generated by
`generate_dummy_kit.generate`.  Connectivity tests use the separate
`tests/_connectivity_artifact.py` fixture and accept only schema
`PS_PROGRESSIVE_FULL_SCALE_DUMMY_CONNECTIVITY_CORRECTION_V0_1` generated by
`generate_connectivity_correction.generate`.

`BASE_CORE_OUTPUTS` and `CONNECTIVITY_CORE_OUTPUTS` in
`final_gate_contract.py` are the single authoritative deterministic replay
scopes.  Packaging receipts, test results, checksums, patches, snapshots, and
ZIP files are excluded from core replay.

Run every repository Python command with `python -B` or
`PYTHONDONTWRITEBYTECODE=1`, then scan the complete worktree for `*.pyc`,
`*.pyo`, and `__pycache__`.  Final sealing is performed from an external copy
of `final_gate_sealer.py` plus `final_gate_contract.py`; no repository module
is imported after the final cleanliness scan.
