# Physical mockup procedure v0.9.3.1

`NO POWER / NO ROTATION / NO BELT TENSION / NO LOAD`

1. Do not energize any motor.
2. Insulate both motor terminals.
3. Mark the 290 mm boundary on the work surface.
4. Place the frame datums.
5. Place CBOX/BBOX templates.
6. Place the inherited track proxy.
7. Install left/right no-load motor jigs.
8. Confirm both front-plate datums.
9. Confirm both shaft centerlines.
10. Measure fixed outer edges.
11. Measure G1 guard outer edges.
12. Measure motor-to-CBOX/BBOX minimum gaps.
13. Measure motor-to-frame minimum gap.
14. Measure motor-to-track proxy minimum gap.
15. Place 20T/60T references or envelope dummies.
16. Check the loose, untensioned belt plane.
17. Place independent selector-shaft witnesses.
18. Check DRIVE indicator position.
19. Check central NEUTRAL position.
20. Check PTO indicator position.
21. Confirm independent inward PTO directions without a common shaft.
22. Place the central unit-bay/support-frame template.
23. Place cable-bend templates.
24. Check outward motor-removal sweep.
25. Check belt-replacement access.
26. Check guard-removal access.
27. Take overview and close-up photographs.
28. Complete every measurement-record row.
29. Attach an interference label to every problem location.
30. End without energizing or rotating the motors.

Stop immediately if a jig deforms the motor bracket, damages insulation, requires force, or creates a fixed intersection.
