# PS-COMMON-ROVER-COMPACT-FIELD-BBOX-V003

1. Print coupon A (0.45 mm groove) and inspect.
2. Install 1.8 mm cord and M4 hardware.
3. Tighten normally to the hard stop.
4. Check copy-paper insertion, visible gap and over-compression.
5. Repeat 10 open/close cycles and inspect the cord.
6. Perform a small inert water exposure when practical.
7. If A is marginal, repeat with coupon B (0.55 mm groove).
8. Only a physical pass releases the full-box print.
