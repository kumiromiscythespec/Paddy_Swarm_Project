# Measurement gaps

The following measurements or source confirmations are required before final BBOX/CBOX internal packaging release.

| Priority | Item | Required evidence | Current classification |
|---|---|---|---|
| P0 | MD10C physical board X/Y | Direct caliper measurement of both installed boards | MEASUREMENT_PENDING |
| P0 | MD10C installed height | Board bottom/standoff datum to highest terminal/component/fastener | MEASUREMENT_PENDING |
| P0 | MD10C service envelope | Terminal protrusion, ferrule, conductor bend, tool and connector-removal clearance | MEASUREMENT_PENDING |
| P0 | Taiyo 2PNCT actual OD | Measure the purchased cable itself at multiple clock positions | MEASUREMENT_PENDING |
| P0 | DC-DC converter | Exact model, body, mounting points, terminal and thermal/service envelope | MEASUREMENT_PENDING |
| P0 | Safety relay | Exact model, coil/contact rating, body, socket and wiring envelope | MEASUREMENT_PENDING |
| P0 | Fuse holders/fuses | Exact holders, final ratings, replacement access, wire and tool envelope | MEASUREMENT_PENDING |
| P0 | E-stop | Exact model, body depth, contact block, bracket, cable and tool envelope | MEASUREMENT_PENDING |
| P1 | ESP32 USB/service | Plug installed envelope, cable bend, removal stroke and RF keep-out | MEASUREMENT_PENDING |
| P1 | XT60 | Confirm whether it is actually selected; measure mated body, bend and unmating stroke | UNKNOWN_REQUIRES_SOURCE_CONFIRMATION |
| P1 | Crimp/ferrule terminals | Select actual parts and measure installed length/width/insulation | MEASUREMENT_PENDING |
| P1 | Capacitors | Confirm circuit requirement, value/voltage, package and retention | UNKNOWN_REQUIRES_SOURCE_CONFIRMATION |
| P1 | Cable glands | Identify each actual gland and measure thread, nut, body, cable range and tool envelope | MEASUREMENT_PENDING |
| P1 | 900 mm service harness | If promotion to PHYSICAL_DIRECT is desired, measure the completed harness end-to-end and record endpoints | MEASUREMENT_PENDING |
| P1 | MD10C hole pattern | Store or cite the exact official drawing, or directly measure the physical board | UNKNOWN_REQUIRES_SOURCE_CONFIRMATION |
| P2 | 9.6 mm cable identity | Photograph/label/continuity record proving whether it is the purchased 2PNCT | UNKNOWN_REQUIRES_SOURCE_CONFIRMATION |

Final fuse ratings, relay rating, E-stop current path, cable ampacity, thermal limit, powered operation, water validation, and field deployment are outside this documentation-only authority.
